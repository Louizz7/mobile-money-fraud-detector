# Dataset

This project uses the PaySim synthetic mobile money transaction dataset.

The raw and processed datasets are excluded from this GitHub repository because of their large file sizes.

## Dataset Structure

- `data/raw/` — Original/raw dataset files.
- `data/processed/` — Cleaned and feature-engineered datasets generated during preprocessing.

## Reproducing the Project

To reproduce the project:

1. Obtain the PaySim dataset from its original source.
2. Place the raw dataset inside `data/raw/`.
3. Run the data preprocessing pipeline.
4. The processed datasets will be generated inside `data/processed/`.
